# Credits and citation information

VideoPlayer is part of an open-source media ecosystem. This page preserves the project's acknowledgments and links to the people and projects being credited.

## Citing VideoPlayer

When mentioning, reviewing, or building on VideoPlayer, link to the [project repository](https://github.com/DARKNIGHT7473/VideoPlayer). Include the release tag or commit you used so others can identify the same version.

Suggested plain-text reference:

```text
Video Player — Android video player.
https://github.com/DARKNIGHT7473/VideoPlayer
Version: <release tag or commit hash>
```

## Keeping credits accurate

Preserve upstream copyright and license notices when adapting code or assets. These acknowledgments supplement, rather than replace, the [project license](LICENSE) and notices accompanying third-party work.

If a credit is missing or incorrect, [open an issue](https://github.com/DARKNIGHT7473/VideoPlayer/issues/new) or a pull request with the relevant source link and the attribution to add or correct.
